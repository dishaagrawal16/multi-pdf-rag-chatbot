
Core Definitions
Term	Definition
GenAI	Subset of DL that generates novel & creative content (text, images, audio, video, code)
LLM	Large Language Model — Transformer model trained on massive text, predicts next word
LVM	Large Vision Model — processes and generates images (e.g., Stable Diffusion, ViT)
Transformer	DL architecture that handles sequential data using self-attention; basis of LLMs
Fine-Tuning	Retraining a pretrained LLM on new/domain-specific data
RAG	Retrieval-Augmented Generation — enhancing LLM with external retrieved documents
Hallucination	LLM generating confident but factually incorrect information
Session State	Streamlit's st.session_state — persists data across reruns within a session
Inference	Testing phase — passing a prompt to a trained model to get output
Prompt Chaining	Breaking a complex task into a sequence of smaller LLM calls (used in Langchain)

Generation Parameters Summary
Parameter	Range	Low Value Effect	High Value Effect
Temperature	0 to 2	Deterministic (boring), Temp=0=Greedy	Creative, random, unpredictable
Top-K	1 to vocab size	Restrictive (only top 1-2 words)	More options, more variety
Top-P	0.0 to 1.0	Conservative (few high-prob words)	Diverse (many candidate words)

 
MEMORY TIPS — Easy Tricks to Remember Concepts

1. GenAI vs LLM: 'LLM is a pet, GenAI is the whole zoo' — LLM is just one animal (text) in GenAI's zoo of models (text, image, audio, video)

2. Temperature = Volume Knob on a Radio. Turn it to 0 → same boring station always. Turn it up → more variety in what plays next.

3. Top-K = 'Top-K Friends' — you only pick your next word from your K best friends (high-prob words). More friends = more variety.

4. Top-P = 'Budget Party' — keep inviting words until the total probability reaches your budget (0.9 = 90%). Everyone invited gets equal chance to speak.

5. Session State = 'Sticky Notes' — normal Streamlit variables get erased each run. Session_state is like a sticky note stuck to the wall — it stays.

6. LLMs are Lazy Thinkers — don't just ask 'What is AI?'. Say 'Think step by step and explain AI like I'm 10, using 3 real-world examples'.

7. OPEN vs CLOSED LLM: 'Open = Share the recipe (code+weights). Closed = Order from the restaurant (pay for output, recipe is secret)'.
